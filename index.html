📱 Come Usare su iPhone & GitHub

1. Pubblicare GRATIS su GitHub Pages

Per avere l'app sempre accessibile online ovunque:

  1. Crea un repository su GitHub (es. Meccanico).
  2. Carica i file di questa cartella (index.html, style.css, app.js, manifest.json, icone).
  3. Vai su Settings > Pages nel tuo repository GitHub.
  4. Sotto Branch seleziona main (o master) e cartella / (root), poi clicca Save.
  5. In 60 secondi il tuo link sarà attivo:
    https://TUO-USERNAME.github.io/Meccanico/

2. Salvare su iPhone come App / Bookmark

  1. Apri il link con Safari sul tuo iPhone.
  2. Tocca l'icona Condividi (il quadrato con la freccia verso l'alto ⬆️ in basso).
  3. Scorri e tocca "Aggiungi alla schermata Home" 📲 (oppure "Aggiungi ai preferiti").
  4. Tocca Aggiungi in alto a destra.

✨ Troverai l'icona personalizzata sulla schermata dell'iPhone e si aprirà a schermo intero come un'app nativa, funzionando anche OFFLINE in pista o nel box senza connessione internet!
